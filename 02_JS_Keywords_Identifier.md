Keywords:
Keywords are reserved words that have a predefined meaning in JavaScript, which we cannot normally use them as variable, function, or class names.
eg - var,let,const,if,else,for etc..

Identifiers:

Identifiers are names that are given to program elements, such as variables, functions, classes, and objects.

eg - username,password, login

Rules for Identifiers:
An identifier can contain:
Letters: a-z, A-Z
Digits: 0-9
Underscore: _
Dollar sign: $
But it cannot start with a number.

Valid eg - 
let username;
let userName;
let user123;
let _username;
let $username;

Invalid eg - 
let 123user;     
let user-name;
